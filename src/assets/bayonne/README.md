## Kit graphic language

Bold torso panel, white edge line, tonal pattern inside the panel, **single crest left chest**, garnet field. Quiet national-team strip confidence — never name the reference kit on-site or in ads.

Commercial creative rules: no student faces, names, or numbers; no manufacturer logos; no “official kit of” claims.
